To build a dashboard like Incident Insights, you need a data source for the incident data, then panels that query it. Your stack has no Incident datasource yet, so that comes first.  

1. **Set up the data source.** Finish the Incident setup in IRM so the Grafana Incident datasource is created. You can also store incident records somewhere else, such as an API you read with your Infinity datasources, or a SQL database.  
2. **Create the dashboard.** Go to **Dashboards → New → New dashboard**.  
3. **Add variables.** Under **Settings → Variables**, add `labels` and `severities` and point them at the incident datasource. Panels can then filter with queries like `or($labels) or($severities)`.  
4. **Add panels like these:**  
   - **Stat:** total incidents (`status:active status:resolved`), security incidents (`label:"security"`), MTTR (mean time to resolve) and PIR (post-incident report) completion.  
   - **Bar gauge:** incidents by severity.  
   - **Time series or bar chart:** daily or monthly incidents and monthly MTTR.  
   - **Gauge:** commander, investigator and task completion rates.  
   - **Table:** a list of incidents, with transformations to rename and order the columns.  
5. **Organize and save.** Group the panels into rows (summary, trends, response, list), set the time range to the last 90 days, and save.  

A quicker way is to import a ready-made template: go to **Dashboards → New → Import**, paste the template, and pick your Incident datasource for `DS_INCIDENT` when asked. Skipping that choice is what broke the current dashboard.
